# ゲキチン（gekichin）

巨大な空中母艦を、戦闘機と僚機で全周から攻める1人用の3D飛行シューティングゲームです。母艦の上・下・左右・前後へ回り込み、装甲の上にある砲台を機銃と機関砲で破壊します。

[ブラウザでゲキチンを開く](https://chameleonjp-lab.github.io/gekichin/)

## 目標と遊び方

- **目標は母艦一隻**：主砲20基と大型機銃80基、合計100基をすべて破壊すると勝利です。
- **六面から攻略**：船体の向こう側へ弾は届きません。面ごとの残り砲台を見ながら、次に回り込む方向を選びます。
- **予告を見て回避**：主砲や機銃が撃つ前の予告を見て、旋回や宙返りで射線から離れます。母艦や海への衝突にも注意が必要です。
- **味方とともに戦う**：総残機は自機を含む50機、同時出撃は8機です。自機を失っても予備があれば復帰し、予備がなくても生存僚機へ操縦を引き継げます。味方残機が0になると敗北です。
- **よりよい成績へ**：砲台への攻撃・破壊とクリアの速さで得点を伸ばし、味方の損失や低い命中率による減点を抑えます。勝利時のベストは端末内にモード別で記録します。

## はじめて遊ぶとき

ホームで難易度を選び、「ルールと操作方法」を確認して「出撃する」を押してください。

- タッチ・マウス：画面を触れた位置からドラッグして操縦します。
- イージー：巡航速度と、照準内の砲台への自動射撃を利用できます。手動ボタンは宙返りです。
- ノーマル：射撃・宙返りの2ボタンと速度レバーを使います。レバーは上で加速、下で減速し、離すと調整した速度を保持します。味方への誤射にも注意してください。
- PC：キーボードでも操縦できます。現在のキー割当はゲーム内説明と「操作設定」で確認・変更できます。

機銃288発と機関砲96発を撃ち切ると6秒で再装填します。音は初期オフで、ゲーム内からオンにできます。説明や操作設定を閉じても自動では戦闘を再開しません。一方、飛行中の「戦況詳細」は一時停止ではなく、開いている間も戦闘と時計が進むため注意してください。

## 開発・検証

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```
